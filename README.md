# KSP Crime Analytics Platform

AI-Powered Crime Analytics & Visualization Platform for Karnataka State Police (KSP).

---

## Overview

KSP Crime Analytics Platform is a modern dashboard application designed to help law enforcement agencies monitor crime trends, identify hotspots, analyze district-wise crime data, and generate actionable intelligence through interactive visualizations.

The platform provides a centralized command center experience with modern UI, analytics dashboards, search capabilities, role-based access, and predictive insights.

## Installation

Clone the repository:

```bash
git clone https://github.com/battulatejasree-spec/ksp-crime-analytics.git
```

Move into the project folder:

```bash
cd ksp-crime-analytics
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## React + Vite

This project is built using React and Vite.

Vite provides fast development, hot module replacement (HMR), and optimized production builds.

Official React plugins supported by Vite:

- @vitejs/plugin-react (Babel based Fast Refresh)
- @vitejs/plugin-react-swc (SWC based Fast Refresh)

- Vite Documentation: https://vitejs.dev
